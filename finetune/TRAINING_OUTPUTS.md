# Training Output Files

This document explains what output files are generated by the training scripts.

## Predictor Training Output (`train_predictor.py`)

### Output Directory Structure

```
./outputs/models/finetune_predictor_us_market/
├── checkpoints/
│   └── best_model/          # Best model checkpoint (saved when val loss improves)
│       ├── config.json      # Model configuration
│       ├── model.safetensors # Model weights (safetensors format)
│       └── ...              # Other model files
└── summary.json             # Training summary and results
```

### Output Files

#### 1. Model Checkpoint: `./outputs/models/finetune_predictor_us_market/checkpoints/best_model/`

**Location**: Based on your config, this is:
```
./outputs/models/finetune_predictor_us_market/checkpoints/best_model/
```

**Contents**:
- `config.json` - Model architecture configuration
- `model.safetensors` - Model weights (or `pytorch_model.bin` in older versions)
- Other model files as needed

**When saved**: The best model is saved whenever validation loss improves during training.

**Usage**: This is the model you'll use for inference/backtesting:
```python
from model import Kronos
model = Kronos.from_pretrained("./outputs/models/finetune_predictor_us_market/checkpoints/best_model")
```

#### 2. Training Summary: `./outputs/models/finetune_predictor_us_market/summary.json`

**Location**: 
```
./outputs/models/finetune_predictor_us_market/summary.json
```

**Contents**: JSON file with training metadata:
```json
{
    "start_time": "2025-12-24T20-46-48",
    "save_directory": "./outputs/models/finetune_predictor_us_market",
    "world_size": 1,
    "final_result": {
        "best_val_loss": 0.1234,
        "best_epoch": 15,
        ...
    }
}
```

**Contains**:
- Training start time
- Best validation loss
- Best epoch number
- Other training metrics

### Console Output

During training, you'll see:
- Training loss per batch
- Validation loss per epoch
- Best model save notifications
- Training progress

Example:
```
[Rank 0, Epoch 1/30, Step 1/2000] LR 0.000040, Loss: 2.3456
[Rank 0, Epoch 1/30, Step 100/2000] LR 0.000040, Loss: 1.2345
...
Best model saved to ./outputs/models/finetune_predictor_us_market/checkpoints/best_model (Val Loss: 0.1234)
Training finished. Summary file saved.
```

## How to Check Output Files

### On AWS Instance

```bash
# Check if training completed
ls -lh ./outputs/models/finetune_predictor_us_market/

# Check checkpoint files
ls -lh ./outputs/models/finetune_predictor_us_market/checkpoints/best_model/

# View training summary
cat ./outputs/models/finetune_predictor_us_market/summary.json

# Check file sizes (model should be large, e.g., 100MB+)
du -sh ./outputs/models/finetune_predictor_us_market/checkpoints/best_model/
```

### Verify Model Can Be Loaded

```bash
python -c "
from model import Kronos
import os

model_path = './outputs/models/finetune_predictor_us_market/checkpoints/best_model'
if os.path.exists(model_path):
    model = Kronos.from_pretrained(model_path)
    print('✓ Model loaded successfully!')
    print(f'✓ Model path: {model_path}')
else:
    print('✗ Model not found. Training may not have completed.')
"
```

## Output File Locations (Based on Your Config)

Based on your `config.py`:

| Component | Output Path |
|-----------|-------------|
| **Tokenizer checkpoint** | `./outputs/models/finetune_tokenizer_us_market/checkpoints/best_model/` |
| **Predictor checkpoint** | `./outputs/models/finetune_predictor_us_market/checkpoints/best_model/` |
| **Tokenizer summary** | `./outputs/models/finetune_tokenizer_us_market/summary.json` |
| **Predictor summary** | `./outputs/models/finetune_predictor_us_market/summary.json` |
| **Backtest results** | `./outputs/backtest_results/` (after running qlib_test.py) |

## Important Notes

1. **Best Model Only**: The script saves only the **best** model (lowest validation loss), not every epoch checkpoint.

2. **Model Size**: Kronos-small checkpoint is approximately **100-200 MB**.

3. **Training Time**: 
   - Tokenizer: ~2-4 hours
   - Predictor: ~4-8 hours
   - Output files are created incrementally

4. **Checkpoint Frequency**: Model is saved whenever validation loss improves, not at fixed intervals.

5. **Resume Training**: The current scripts don't support resuming from checkpoint. If training fails, you need to restart.

## Downloading Outputs from AWS

To download the trained model to your local machine:

```bash
# From your local machine
scp -i your-key.pem -r ubuntu@your-instance-ip:/home/ubuntu/Kronos_test/outputs/models ./local_outputs/
```

Or use AWS S3:

```bash
# On AWS instance
aws s3 cp ./outputs/models s3://your-bucket/kronos-models/ --recursive

# Download locally
aws s3 cp s3://your-bucket/kronos-models/ ./local_outputs/ --recursive
```

## Using the Trained Model

After training completes, use the model for inference:

```python
from model import Kronos, KronosTokenizer, KronosPredictor

# Load finetuned models
tokenizer = KronosTokenizer.from_pretrained("./outputs/models/finetune_tokenizer_us_market/checkpoints/best_model")
model = Kronos.from_pretrained("./outputs/models/finetune_predictor_us_market/checkpoints/best_model")

# Create predictor
predictor = KronosPredictor(tokenizer=tokenizer, model=model)

# Use for predictions
# ... (your prediction code)
```
